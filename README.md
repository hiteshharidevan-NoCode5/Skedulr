# Skedulr

A freeform transparent calendar app and widget for Android. Features month-by-month swipe navigation, standard and transposed orientations, event additions, custom text scales/colors, and inclusive regional Indian Holidays & Malayalam Calendar (Sabarimala Season Tracker).

## Custom Icon
Features a peaceful minimalist clock-face character—utilizing your creative drawing with the "V"-shape nose and brow doubling as clock hands.

---
Built from open-source resources using Android Adaptive Vectors and standard Android SDK bounds.
